Sensibilidade sai só dos positivos de referência e especificidade só dos negativos, então trinta amostras todas negativas não estimam sensibilidade nenhuma. Dizer isso aqui é o que evita o estudo chegar ao fim com uma metade vazia. {% endcomment %}

{% comment %} Seleção múltipla: a grade se comporta como a planilha de onde o laboratório veio. Limpar esvazia os campos; quem apaga do estudo é o botão de salvar, que é a regra de gravação que já existia. {% endcomment %}

Para corrigir vários de uma vez: arraste sobre as células, Shift+clique para marcar um retângulo ou Ctrl+clique (Cmd no Mac) para marcar avulsas. Depois Delete, ou o botão que aparece no rodapé. Limpar não apaga do estudo — quem apaga é o salvar, e Ctrl+Z devolve o que foi limpo ou colado por engano.
